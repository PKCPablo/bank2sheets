# run.ps1 JDK 21 discovery Implementation plan

**Goal:** Make `scripts/run.ps1` resolve and launch a JDK 21+ `java.exe` the same way `scripts/mvn.ps1` resolves `JAVA_HOME`, so the runner works on this machine where `java` is not on `PATH` and `JAVA_HOME` points at JDK 8.

**Architecture:** Pure PowerShell wrapper change. `run.ps1` keeps its current order (JAR-missing check → `.env` load → exec) but inserts a JDK 21+ resolver between the JAR check and the `.env` load, then invokes the resolved `java.exe` by absolute path instead of bare `java`. No Java code, `pom.xml`, `mvn.ps1`, or CLI contract changes.

**Tech Stack:** Windows PowerShell 5.1+/PowerShell 7, Maven 3.9.9 wrapper, JDK 21 (Temurin 21.0.12).

**Scope classification:** `single-task`

## Verified baseline (2026-10-27, this machine)

- `JAVA_HOME=C:\Program Files\Java\jdk-1.8`; `Get-Command java` returns nothing (no `java` on `PATH`).
- Installed JDKs: `jdk-1.8`, `jdk-11`, `jdk-21` under `C:\Program Files\Java`; `jdk-21\bin\java.exe -version` → `openjdk version "21.0.12"`.
- `target\bank2sheets-0.1.0-SNAPSHOT.jar` exists; `& 'C:\Program Files\Java\jdk-21\bin\java.exe' -jar <jar> help` prints usage and exits 0.
- `.\scripts\run.ps1 help` **fails today**: `CommandNotFoundException` for `java` at line 33, and the script still **exits 0** because a command-not-found error leaves `$LASTEXITCODE` unchanged (extra defect captured by this plan; the fix removes it because the executable path always resolves or the script exits 1).
- `scripts/mvn.ps1` already contains the detector to mirror: `Get-JavaHomeMajorVersion`, `Get-JdkNameVersion`, `jdk-21*` scan under `C:\Program Files\Java`, actionable `Write-Error` + `exit 1`.
- Working tree is clean (`git status --porcelain` empty). `.env` exists and is gitignored.

## Decisions

- **Duplicate the detector in `run.ps1` instead of extracting `scripts/jdk.ps1`.** The issue scopes changes to `run.ps1` only and forbids touching `mvn.ps1`; a shared helper would require re-validating the Maven wrapper. Duplication is ~35 lines and is recorded as a deferred simplification (see Follow-ups).
- **Resolve an absolute `java.exe` and do not mutate `$env:JAVA_HOME`.** `mvn.ps1` mutates `JAVA_HOME` because Maven reads it; the JAR does not, so the runner stays side-effect free and only needs the executable path.
- **Resolution order** (per issue #2): `JAVA_HOME\bin\java.exe` ≥ 21 → highest `jdk-21*` under `C:\Program Files\Java` → `java` on `PATH` ≥ 21 → actionable error, `exit 1`.
- **Keep the `.env` block, the `-JarPath` parameter, and app-argument handling byte-for-byte unchanged.** JDK resolution runs before `.env` loading so a broken JDK fails without mutating the process environment.
- **Version parsing** reuses the `mvn.ps1` regex `version "(\d+)"`: JDK 8 reports `1.8.0_x` → major `1` → rejected, which is the desired behavior.

```powershell
# Resolve a JDK 21+ (the machine default JAVA_HOME is JDK 8 and java is not on PATH).
$jdkRoot = 'C:\Program Files\Java'

function Get-JavaExeMajorVersion {
    param([string]$JavaExe)

    if ([string]::IsNullOrWhiteSpace($JavaExe) -or -not (Test-Path -LiteralPath $JavaExe)) {
        return $null
    }

    $versionLine = & $JavaExe -version 2>&1 | Select-Object -First 1
    if ($versionLine -match 'version "(\d+)') {
        return [int]$matches[1]
    }

    return $null
}

function Get-JdkNameVersion {
    param([string]$Name)

    $raw = $Name -replace '^jdk-', ''
    if ($raw -notmatch '\.') {
        $raw = "$raw.0"
    }
    if ($raw -match '^\d+(\.\d+)+$') {
        return [version]$raw
    }

    return [version]'0.0'
}

function Resolve-Java21Exe {
    if (-not [string]::IsNullOrWhiteSpace($env:JAVA_HOME)) {
        $javaHomeExe = Join-Path $env:JAVA_HOME 'bin\java.exe'
        if ((Get-JavaExeMajorVersion $javaHomeExe) -ge 21) {
            return $javaHomeExe
        }
    }

    $candidates = @(
        Get-ChildItem -LiteralPath $jdkRoot -Directory -Filter 'jdk-21*' -ErrorAction SilentlyContinue |
            Where-Object { Test-Path -LiteralPath (Join-Path $_.FullName 'bin\java.exe') } |
            Sort-Object -Property @{ Expression = { Get-JdkNameVersion $_.Name }; Descending = $true }, Name -Descending
    )

    foreach ($candidate in $candidates) {
        $candidateExe = Join-Path $candidate.FullName 'bin\java.exe'
        if ((Get-JavaExeMajorVersion $candidateExe) -ge 21) {
            return $candidateExe
        }
    }

    $pathJava = (Get-Command java -CommandType Application -ErrorAction SilentlyContinue |
        Select-Object -First 1).Source
    if ((Get-JavaExeMajorVersion $pathJava) -ge 21) {
        return $pathJava
    }

    return $null
}

$javaExe = Resolve-Java21Exe
if (-not $javaExe) {
    Write-Error "No JDK 21+ found. Install JDK 21+ or set JAVA_HOME (or PATH) to a JDK 21+ installation."
    exit 1
}
```
